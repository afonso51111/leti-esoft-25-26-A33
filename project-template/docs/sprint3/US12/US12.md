# US 12 - Specify a new vaccine type

## 1. Requirements Engineering

### 1.1. User Story Description

As DGS Administrator, I want to specify a new vaccine type.

### 1.2. Customer Specifications and Clarifications

**From the specifications document:**

> The Administrator must be able to define the types of vaccines available in the system (e.g., Covid-19, Dengue, etc.), characterizing them by a code, a short description, and the target disease.

**From the client clarifications:**

> n/a (No specific clarifications provided in the forum for this US. Standard business rules apply).

### 1.3. Acceptance Criteria

- AC12-1: The Vaccine Type Code must be unique within the system.
- AC12-2: The Code must consist of alphanumeric characters (e.g., 5 chars).
- AC12-3: The Short Description and Disease fields cannot be empty.

### 1.5 Input and Output Data

**Input Data:**

- Typed data:
    - Code
    - Short Description
    - Disease

**Output Data:**

- (In)success of the operation

## 4. Tests

**Test 1:** Check that it is possible to create an instance of Vaccine Type with valid values.

    TEST_F(VaccineTypeFixture, CreateValidType){
        EXPECT_NO_THROW(new VaccineType(L"12345", L"Covid-19 Vaccine", L"Covid-19"));
    }

**Test 2:** Check that it is not possible to create a type with an empty code/description.

    TEST_F(VaccineTypeFixture, CreateWithEmptyCode){
        EXPECT_THROW(new VaccineType(L"", L"Description", L"Disease"), std::invalid_argument);
    }

**Test 3:** Check that the store rejects saving a type with a duplicate code (validates AC12-1).

    TEST_F(VaccineTypeStoreFixture, FailToSaveDuplicateCode){
        shared_ptr<VaccineType> vt1 = this->store->create(L"12345", L"Desc A", L"Dis A");
        this->store->save(vt1);

        shared_ptr<VaccineType> vt2 = this->store->create(L"12345", L"Desc B", L"Dis B");

        EXPECT_THROW(this->store->validate(vt2), std::runtime_error); 
    }
