# US 15 - Get a list of employees assigned to a specific function/role

## 1. Requirements Engineering

### 1.1. User Story Description

As a **DGS Administrator**, I want to get a list of employees assigned to a specific function/role.

### 1.2. Customer Specifications and Clarifications

**From the specifications document:**

> Each employee plays a specific role in the system, defined by their category (e.g., **Nurse**, **Receptionist**).
> DGS Administrators can view employees and filter them by their assigned category.
> Employee data includes **name**, **postal address**, **phone number**, **email**, and **citizen card number**.

**From the client clarifications:**

> **Question:** Can Administrators list all employees, or only those of one role at a time?
>
> **Answer:** Only one role (category) at a time; listing all employees can be another US.
>
> > **Question:** What data must appear in the returned list?
>
> **Answer:** At minimum: Name, Phone, Email, and Role/Category.

### 1.3. Acceptance Criteria

- AC15-1: The system must allow the Administrator to select exactly one valid role (Nurse, Receptionist) from the available employee types.
- AC15-2: The system must return all employees who are instances of the selected role.
- AC15-3: If no employees exist for the selected role, an empty list must be returned.
- AC15-4: Returned employees must be sorted in ascending order by name.
- AC15-5: For each employee, the system must return the following fields: Name, Phone Number, E-mail Address, and Role.

### 1.4. Found out Dependencies

- Depends on EmployeeStore (must store employees and allow filtering).
- Depends on Company (access point to the store).
- Depends on Employee (and subclasses Nurse, Receptionist).
- Can be implemented after US14 is completed.

### 1.5 Input and Output Data

**Input Data:**

- Selected data:
  - Nurse
  - Receptionist

**Output Data:**

- employee
- name
- phoneNumber
- email
- role/category

## 4. Tests

Three relevant test scenarios are highlighted next, focusing on the EmployeeStore responsibilities (filtering by type and sorting).

**Test 1:** Check that the system returns only the employees matching the requested class type (validates AC15-1 and AC15-2).

     TEST_F(EmployeeStoreFixture, ListEmployeesByRoleReturnsCorrectMatches) {
        // Arrange: Create employees of different types
        shared_ptr<Employee> nurse = std::make_shared<Nurse>(L"Nurse Mary", L"Address 1", L"910000001", L"mary@mail.com");
        store->add(nurse);
        
        shared_ptr<Employee> recep = std::make_shared<Receptionist>(L"Recep John", L"Address 2", L"910000002", L"john@mail.com");
        store->add(recep);

        // Act: Request only Nurses (using "Nurse" string or enum mapped to class)
        std::list<shared_ptr<Employee>> results = store->getEmployeesByRole("Nurse");

        // Assert: Should find 1 nurse, and it must be Mary
        EXPECT_EQ(results.size(), 1);
        EXPECT_EQ(results.front()->getName(), L"Nurse Mary");
    }

**Test 2:** Check that the returned list is sorted by name in ascending order (validates AC15-4).


     TEST_F(EmployeeStoreFixture, ListEmployeesByRoleReturnsSortedByName) {
     // Arrange: Add Nurses in unsorted order (Zack then Alice)
     shared_ptr<Employee> emp1 = std::make_shared<Nurse>(L"Zack", L"Address", L"910000001", L"zack@mail.com");
     store->add(emp1);

     shared_ptr<Employee> emp2 = std::make_shared<Nurse>(L"Alice", L"Address", L"910000002", L"alice@mail.com");
     store->add(emp2);

        // Act
        std::list<shared_ptr<Employee>> results = store->getEmployeesByRole("Nurse");

        // Assert: Alice should come before Zack
        auto it = results.begin();
        EXPECT_EQ((*it)->getName(), L"Alice");
        it++;
        EXPECT_EQ((*it)->getName(), L"Zack");
    }


**Test 3:** Check that an empty list is returned if no employees exist for the selected role (validates AC15-3).

      TEST_F(EmployeeStoreFixture, ListEmployeesByRoleReturnsEmptyWhenNoMatches) {
        // Arrange: Store has a Nurse, but no Receptionists
        shared_ptr<Employee> emp1 = std::make_shared<Nurse>(L"Alice", L"Address", L"910000001", L"alice@mail.com");
        store->add(emp1);

        // Act: Request Receptionists
        std::list<shared_ptr<Employee>> results = store->getEmployeesByRole("Receptionist");

        // Assert
        EXPECT_TRUE(results.empty());
    }
